# 学习管理 · 个人课程管理

一个面向大学生的纯前端课程管理工具，把「课程信息、作业、学习规划」装进一个网页，
并用 AI 辅助学习。无后端、无框架、无构建步骤，双击 `index.html` 即可使用，
所有数据只保存在你自己的浏览器里。

## ✨ 功能

- **课程简介**：课程卡片式管理，鼠标悬停课程名即可查看老师、邮箱、作业平台、资源等详情
- **作业管理**：布置 / 编辑 / 删除作业，勾选完成文字自动变淡；逾期红色提醒；
  按周、按课程筛选，完成进度一目了然
- **学习规划**：以「学习目标流程图」呈现——时间为纵轴、前置依赖为连线，
  支持起始 / 结束日期，自动检测依赖环，引导你的学习路径
- **AI 助手（可选）**：接入 DeepSeek，一键审阅学习规划、辅导作业、推荐教程；
  填入自己的 API Key 即可，不填也能用其余全部功能

## 🛠 技术特点

- 原生 HTML / CSS / JavaScript，零第三方依赖、零构建
- SVG 手绘流程图 + 拓扑分层布局
- localStorage 本地持久化，数据不上传任何服务器
- AI 由浏览器直连 DeepSeek，Key 仅存本机

## 🚀 使用

1. 下载或克隆本项目
2. 双击 `index.html`（或任意静态服务器打开）
3. 可选：在「AI 助手」页填入 DeepSeek API Key

## 配置 AI 助手（可选）

进入「AI 助手」标签，填入你自己的 [DeepSeek API Key](https://platform.deepseek.com) 并保存即可（Key 仅保存在本机浏览器）。若没有 Key，其余模块不受影响。
